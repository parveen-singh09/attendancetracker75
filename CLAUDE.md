# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository layout

The git repository root is `attendance-calculator/`, but the actual application lives in the `my-app/` subdirectory. **All `npm` and `astro` commands must be run from `my-app/`, not from the repo root.** There is no package.json at the repo root.

Despite the repo name "attendance-calculator", the codebase is currently the unmodified Astro `basics` starter template (`src/pages/index.astro` renders the default `Welcome.astro` splash). Application features for an attendance calculator have not been built yet.

## Commands

Run from `my-app/`:

| Command | Purpose |
| --- | --- |
| `npm install` | Install dependencies |
| `npm run dev` | Start dev server on `localhost:4321` |
| `npm run build` | Build production site to `./dist/` |
| `npm run preview` | Preview the production build locally |
| `npm run astro -- <cmd>` | Run Astro CLI (e.g. `npm run astro -- check` for type-checking, `npm run astro -- add <integration>` to install integrations and update `astro.config.mjs`) |

No test runner, linter, or formatter is configured. Type-checking is done via `astro check` (uses the strict tsconfig).

## Stack & conventions

- **Astro 6.4.x** (see `my-app/package.json`). When consulting docs or making non-trivial changes, prefer the Astro 6 docs — several APIs changed from Astro 5.
- **Node >= 22.12.0** is required (`engines` in `package.json`).
- **TypeScript** extends `astro/tsconfigs/strict`. Generated types live in `my-app/.astro/types.d.ts` (gitignored; regenerated by `astro dev`/`astro check`).
- `astro.config.mjs` is intentionally empty (`defineConfig({})`). Add integrations with `npm run astro -- add <name>` so the config and dependencies are kept in sync.

## Standard Astro source layout (in `my-app/src/`)

- `pages/` — file-based routing; each `.astro` file becomes a route.
- `layouts/` — wrapper components that render `<slot />` (see `Layout.astro` for the base HTML shell).
- `components/` — reusable `.astro` components.
- `assets/` — imported assets processed by Astro (use `image.src` when binding to `<img>`).
- `public/` — static files served as-is from the site root.
